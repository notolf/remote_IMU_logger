# Brand assets

Drop the official Leica Geosystems logo here as `leica_logo.svg`
(preferred), `leica_logo.png`, or `leica_logo.jpg` — get it from the
internal brand portal. `evaluate_level_log.py` embeds it into every
report automatically; without it, reports fall back to a typographic
wordmark. See `docs/DESIGN.md` before committing binaries to a public
repository.
