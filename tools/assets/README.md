# Brand assets

Drop the official Leica Geosystems logo into this folder as any
`.svg` / `.png` / `.jpg` file (e.g. `Leica_Geosystems.png`) — get it
from the internal brand portal. `evaluate_level_log.py` embeds it into
every report automatically; if several images exist, `leica_logo.*` is
preferred. Without an asset, reports fall back to a typographic
wordmark. See `docs/DESIGN.md` before committing binaries to a public
repository.
